Chaplin — Movie Streaming Backend

Учебный pet-проект: backend для стримингового сервиса, демонстрирующий работу с P2P-протоколом (BitTorrent/WebTorrent), потоковой передачей видео через HTTP Range-запросы и интеграцией с внешним API (TMDB).

Цель проекта — отработка инженерных задач: потоковая передача больших файлов по кускам (chunked streaming), работа с P2P-протоколами на Node.js, HTTP Range-запросы для перемотки видео, интеграция с внешними REST API.

Стек
Node.js + TypeScript (ESM-модули)
Express 5 — REST API
MongoDB + Mongoose — хранилище метаданных фильмов
WebTorrent — P2P-стриминг видео
TMDB API — источник метаданных о фильмах (постеры, описания, актёры, трейлеры)
Cheerio + Axios — парсинг торрент-раздач


Установка и запуск
1. Поднять MongoDB через Docker
bash
docker-compose up -d
2. Переменные окружения


bash
cp .env.example .env
MONGO_URL=mongodb://localhost:27017/enjoyFilm
IMDB_API_KEY=<твой TMDB API key>
PORT=5000

API-ключ получить бесплатно на themoviedb.org — несмотря на название переменной (IMDB_API_KEY), используется именно TMDB API.

3. Установка зависимостей и запуск
bash
npm install
npm run dev      # разработка (nodemon + tsx)
npm run build    # сборка в dist/
npm start        # запуск собранной версии

Сервер поднимется на http://localhost:5000.


Важные технические детали
Стриминг без сохранения на диск — видео передаётся напрямую из P2P-потока в HTTP-ответ через createReadStream, что позволяет начинать воспроизведение ещё до полной загрузки файла.
Умный выбор раздачи — при поиске сортировка учитывает разрешение (оптимум — 1080p, а не максимально возможное), избегает Remux-раздач (слишком большой размер) и UHD/4K (избыточно для стриминга).
Не транскодирует видео — сервер отдаёт исходный поток "как есть". Совместимость со звуком/видео зависит от кодеков конкретной раздачи (браузеры нативно не декодируют некоторые аудиокодеки вроде AC3/DTS).
